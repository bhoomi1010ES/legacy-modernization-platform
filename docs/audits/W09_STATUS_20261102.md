No generic fallback is allowed. `sandbox_protocol.validate_check_profile` requires distinct checks and rejects `compileall` under any category except `build`. Empty pytest runs become `NOT_RUN` for unit, integration, runtime, API compatibility, and schema checks.
- Expired API worker leases now terminalize any unfinished `VerificationRun` as immutable `BLOCKED` evidence. Its provider response cannot be reused by a subsequent attempt; new work needs a new independent run.
- The WSL API restart helper preserves the configured database credentials in memory while changing only the database host to the WSL default gateway. It verifies both the API and the actual Vite proxy.
